# Block 7: Bericht erstellen

## Ziele

* Sie wissen, was R Markdown ist und woran Sie eine `.Rmd`-Datei erkennen
* Sie unterscheiden Text, Chunk und Inline-Code
* Sie sehen, dass Chunks mit Optionen gesteuert werden können: `echo`, `eval`, `results`, `warning`, `message`
* Sie haben gesehen wie Grafiken und Tabellen in einen Bericht eingebaut werden
* Sie kennen HTML-Widgets (`leaflet`, `DT`) für interaktive Berichte
* Sie erzeugen aus einer Quelldatei die Ausgabeformate HTML, PDF und Word
