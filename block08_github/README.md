# Block 8: GitHub und Opencode

## Ziele

* Sie verstehen, warum Versionskontrolle für reproduzierbare Auswertungen im ÖGD nützlich ist
* Sie legen ein GitHub-Konto an
* Sie klonen ein Repository in RStudio, über das Terminal oder den Git-Reiter
* Sie speichern Änderungen mit commit und laden sie mit push hoch
* Sie geben Material an Kolleginnen und Kollegen weiter, auch ohne dass diese Git benutzen
* Sie ordnen Opencode und vergleichbare offene Werkzeuge ein
