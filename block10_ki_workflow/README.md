# Block 10: Arbeiten im KI-Chat und mit Claude Code

## Ziele

* Sie kennen den Unterschied zwischen einem KI-Chat im Browser und einem KI-Werkzeug, das direkt auf Ihre Dateien zugreift
* Sie beschreiben einen Datensatz so, dass ein Sprachmodell brauchbaren R-Code liefert
* Sie spielen Fehlermeldungen zurück und arbeiten iterativ auf ein Ergebnis hin
* Sie beurteilen den erzeugten Code kritisch, statt ihn ungeprüft zu übernehmen
* Sie kennen die datenschutzrechtlichen Grenzen im Gesundheitsamt
