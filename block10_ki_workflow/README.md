# Block 10: Arbeiten im KI-Chat und mit Claude Code

Referentin/Referent: noch offen

Status: Gerüst. Die Inhalte werden noch ergänzt.

## Lernziele (geplant)

* Sie kennen den Unterschied zwischen einem KI-Chat im Browser und einem KI-Werkzeug, das direkt auf Ihre Dateien zugreift
* Sie beschreiben einen Datensatz so, dass ein Sprachmodell brauchbaren R-Code liefert
* Sie spielen Fehlermeldungen zurück und arbeiten iterativ auf ein Ergebnis hin
* Sie beurteilen den erzeugten Code kritisch, statt ihn ungeprüft zu übernehmen
* Sie kennen die datenschutzrechtlichen Grenzen im Gesundheitsamt

## Geplanter Ablauf der Demonstration

1. Ausgangslage: ein unbekannter Datensatz und eine Fragestellung
2. Den Datensatz beschreiben, Struktur und Spalten nennen
3. Ein Analyseskript erzeugen lassen
4. Das Skript ausführen, Fehlermeldung zurückspielen, korrigieren lassen
5. Aus dem Ergebnis einen Bericht erzeugen lassen
6. Gegenprobe: Stimmt das Ergebnis? Wo hat das Modell etwas erfunden?

## Datenschutz

Personenbezogene oder besondere Kategorien personenbezogener Daten nach
[Art. 9 DSGVO](https://dsgvo-gesetz.de/art-9-dsgvo/), zu denen Gesundheitsdaten
gehören, dürfen nicht in einen externen Chatdienst eingegeben werden. Für den
Kurs und für die Demonstration gilt: nur offene oder synthetische Daten.
Vor jedem dienstlichen Einsatz ist die Freigabe der eigenen Behörde und der
Datenschutzbeauftragten einzuholen.
